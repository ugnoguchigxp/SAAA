# Adaptive improvement baseline

Recorded: 2026-09-21

The existing production path selected a lexicographically stable, eligible role-routing recipe.
Tool selection, steward planning, and schedule notifications retain their established hard filters
and rules. There was no shared, production-safe adaptive policy layer.

The baseline rule remains the fallback for every domain: an override, artifact, or its candidate
set that is absent, stale, invalid, or not eligible cannot alter an action.
