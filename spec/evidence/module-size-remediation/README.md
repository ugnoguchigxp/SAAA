## 全体合格に向けて残るもの

1. 品質評価の `harness_runs_the_persisted_conversation_runtime_path` が、削除済みの旧会話経路を呼ぶ。現在の会話キューに評価の呼び出しと期待値を移す必要がある。[全体検査の実行記録](full-check.log)を参照。
2. 旧音声セッションのテストは、既に存在しない `useAmbientVoiceSession` と `ambientVoiceCaptureActions` を参照する。現在の連続ASRと会話キューに、適用可能な検査を移す必要がある。旧テストに含まれる再生中の一括抑止を復活させて合格にすることは、現在の音声契約に反する。
3. Dynamic LANの既存テスト1件は、診断用の通信経路へ旧Context・永続化を要求する。現在の通信経路はその要求を `Unavailable` として拒否するため失敗する。接続の検査と、現在の会話経路での保存の検査を整合させる必要がある。
4. Rust全体の整形検査には、今回未変更の30ファイルに差分が残る。[整形検査の出力](global-rust-format.log)を参照。
5. Clippyの全体検査には、現行の警告基準を超える404種類のキーが残る。これは検査基準との比較であり、今回新しく発生した警告の数ではない。未使用の旧経路、引数数、移動先の警告パスなどを確認する必要がある。警告の許容値をまとめて広げる変更はしていない。

全Rust単体試験も試みたが、旧会話経路のfallbackテストが送信されない要求を待ち続けたため停止した。停止までに36件の失敗を観測しており、全件の合格確認とは扱わない。残る問題の一覧は[remaining-checks.json](remaining-checks.json)に保存した。

サイズ検査の是正は完了している。全体検査の合格と、メモリ機能の実モデルでの受け入れ完了は、引き続き別の未完了項目として扱う。Context取得・評価は今回各1回、累計各6回。
