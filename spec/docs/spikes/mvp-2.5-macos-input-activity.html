Question

objc2-core-graphics 0.3.2の固定featureで、event tapやraw event収集を行わず、 shipping targetからlast-input durationを取得して同一call stack内でbounded categoryへ変換できるか。

Implementation

objc2-core-graphics = { version = "0.3.2", default-features = false,
  features = ["std", "CGEventSource", "CGEventTypes"] }

CGEventSource::seconds_since_last_event_type(CombinedSessionState, CGEventType(u32::MAX)) を使用した。finite、non-negative、overflowを検査し、floor後に30秒/5分のcategory境界へ変換する。

Automated results

  • boundary、fraction、NaN、Infinity、negative、overflowのpure testが成功。
  • macOS live CoreGraphics callがbounded categoryだけを返すtestが成功。
  • monitoring disabled pathはplatform adapterを呼ばず、disabled signalを返す。
  • debug packaged desktop smokeはmonitoring onで1 sampleを取得し、offへ戻す。
  • 30分・2秒間隔のlive sampling soakは1801.54秒で成功し、890 sample以上とRSS増加32 MiB以下のassertを満たした。

Manual results still required

  • keyboard、mouse、trackpad後のActive resetと、Recent、Idleへの実時間遷移。
  • screen lock/unlock、sleep/resume。
  • development buildと署名済みpackaged buildでpermission promptが出ないこと。
  • Debugger symbolic breakpointによるmonitoring off時のAPI call 0回確認。

Conclusion

dependency、symbol、link、bounded projectionは採用可能である。releaseおよび計画archiveは、 上記manual lifecycle evidenceが記録されるまで保留する。
