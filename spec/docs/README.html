Internal Design Documents

このdirectoryには、進行中のimplementation plan、現行実装のrelease evidence、 恒久contract、shared conceptだけを置く。

内部設計書はSpec HTML fragmentで管理する。bun run spec:viewで閲覧し、 編集後はbun run spec:fixとbun run spec:checkを実行する。

実装と検証が完了した計画およびそのrelease evidenceは、ViewerのArchive操作で .archived/へ移す。単なるファイル移動ではなく、 archive ruleに従う。
