Archived Internal Design Documents

このdirectoryは、実装と受け入れが完了した計画、または後続計画で置換済みの内部文書を保持する。

  • 現在の要件、未完了作業、実装順序の入口として扱わない。
  • 現行挙動はcode、tests、およびspec/docs/のactive documentsを優先する。
  • Archive対象は、計画のStatusがCompleteで、対応するrelease evidenceがAcceptedである文書とする。 後続文書で置換する場合は、置換先または理由を本文に記録する。
  • 恒久contractであるADRと、未完了・提案中の計画はArchiveしない。
  • 文書はactive documentと同じSpec HTML fragment形式を保ち、 bun run spec:viewのArchived表示から参照する。
  • ArchiveはSpec HTML ViewerのArchive操作で行う。移動後に bun run spec:fixとbun run spec:checkを実行する。
  • このhidden directoryは、通常のfile discoveryで完了済み計画がactive contextへ混入することを防ぐ。

Archive policy adopted on 2026-08-27.
