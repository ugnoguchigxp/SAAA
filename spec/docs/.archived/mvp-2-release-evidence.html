Shipping capabilities

  • Microphone Meeting Session: implemented.
  • System audio, floating overlay, translation: unavailable in this build (P0 gates not passed).

Verified automated evidence

  • SQLite migration creates the v6 meeting metadata and transcript tables, preserves a v5 fixture, and reconciles unfinished metadata to interrupted with zero persisted transcript entries.
  • Explicit Save writes final in-memory entries transactionally; Discard leaves no transcript body for its session.
  • Chat and Meeting encode WAV data in memory and send it only to the fixed private-network LLM server ASR adapter. No temporary raw-audio file is created.
  • Frontend queue tests cover two-item backpressure and PCM frame boundaries. Rust covers preflight, token entropy, segment validation, pause cancellation, TTS policy, Save/Discard, and migration/reconcile.
  • Chat emits a real ASR preview after approximately two seconds. Meeting emits TranscriptPartial for the current lane/sequence and replaces it with TranscriptFinal; a late preview cannot consume or overwrite a final sequence.
  • Save requires a review of target, final entry count, detected languages, and raw-audio deletion. The detected language is persisted in original_language. Discard has a separate destructive confirmation.
  • The 2026-08-29 workspace-wide suite reports 46 frontend tests passed and 156 Rust tests passed, with 8 operator-only or external-runtime tests intentionally ignored.
  • bun run check, bun run build, and bun run desktop:smoke passed on macOS. The packaged application starts successfully with an isolated smoke-test data directory.

Manual desktop evidence still required before a production release

  • Test the real LLM server ASR node with microphone permission grant, denial, and revocation, and confirm that a two-second preview is visibly replaced by the final transcript.
  • Run 30-minute and 2-hour resource soak tests; verify pause/stop/unmount release the microphone indicator.
  • Verify the Save review contents, Save-before/after database entry counts including original_language, Discard, app-close cleanup, and TTS blocking on macOS.

Known limitation: LLM server ASR is a non-streaming endpoint. SAAA obtains a bounded interim result through a short preview request and finalizes fixed five-second Meeting segments. Segment boundaries can omit a word; no LLM correction, speaker attribution, cloud fallback, notification, or automatic action is performed.
