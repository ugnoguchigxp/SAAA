3. Cutover

  1. 直前releaseのDesktopとServer artifact digest、DB backup、設定exportを固定する。
  2. Serverのversioned WebSocketをtrafficなしでcontract testし、広告本数をprewarmする。
  3. SSE serverを停止したisolated環境でfunctional canaryを実行する。
  4. 対象DesktopとServerを同時にcanaryへ投入し、Text、TTS、ASRを別々に判定する。
  5. 全Gateと30分soakに署名後だけ対象範囲を拡大する。

4. WebSocket-only rollback

  1. 新規turnの受付を止め、active LLM runだけをcancelする。ASR sessionと確定済みTextは維持する。
  2. 当該runの未再生TTS artifactとprocessを破棄し、他speech sessionへ波及させない。
  3. DesktopとServerを、事前固定した直前の互換releaseへ同時に戻す。
  4. 新Desktop内でSSE fallback、gateway、設定切替を有効化しない。
  5. 再起動後、WS接続、通常3 turn、cancel、ASR、TTS、DB整合性を確認する。
  6. artifact hash、時刻、operator、失敗Gateだけを記録し、本文は記録しない。
