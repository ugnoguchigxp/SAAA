Implementation plan
MVP 2.5 Implementation Plan

Implemented

  • Codex coding routeにrequest/progress/terminal-gap/hard watch、one-shot interrupt、bounded drain、kill/wait、reader joinを導入。
  • foreign、unscoped、duplicate itemをprogressから除外し、forbidden itemとserver requestをpolicy violationへ写像。
  • bounded failure code、Supervisor version、last-progress timestampをv7 SQLiteへ保存。
  • Codex success/failure/cancelは同一transaction commit後にterminal Tauri eventを1件だけ送信。
  • 通常会話のassistant message、conversation更新、Runtime Run完了も同一transactionで確定し、 commit後にmessageCompleted eventを送信。
  • macOS Input Activityをcategory化し、raw durationをadapter外へ出さない。
  • Input Activityはclassifier stateを変えず、idle Ready時のShadow SUGGESTだけをOBSERVEへ抑制。
  • v1/v2 replay、attention metrics、candidate threshold editor、frontend strict contractを追加。
  • Runtime、Voice、MeetingのTauri event fieldをfrontend contractどおりcamelCase化し、 serialization回帰testを追加。
  • request待ちを次deadlineまでに制限し、foreign response floodによるtimeout飢餓を防止。 stdout readerはAgent Runとstatus/model lookupの双方で4 MiB + 1 byteに物理的に制限する。
  • cancellation通知をlate waiterでも観測できるようにし、当時のWhisper process readerのbounded queue、全終了経路の kill/wait/join、Runtime Runとprovider sessionのone-shot finalizationを追加した。Voiceの現行実装はgnosis ASR HTTP adapterへ移行済みである。

start、resume、cancel応答あり/なし、thread/turn request hang、progress hang、terminal gap、hard timeout、malformed JSON、provider error、failed terminal、approval request、fileChange/MCP/dynamic tool/Web Search、child exit、foreign/unscoped、duplicate item、invalid thread/turn id、64,001文字、4 MiB超streamを同一fixtureで検証する。 foreign response floodがrequest deadlineを延命しないことも別testで確認する。各runはcleanup後にreturnし、 failure codeとrunごとのinterrupt上限を検査する。

Privacy evidence

  • DTOとfrontend schemaはcategoryとhealthだけを許可し、exact duration/last-input fieldをstrictに拒否する。
  • SQLite、diagnostics、ledgerへraw durationまたはraw app-server eventを追加していない。
  • provider errorとfailed terminalのraw messageを固定文言へ変換し、永続化境界へ渡さない。
  • Model ProviderのHTTP redirectを追従せず、loopback/local-only境界の迂回を防止する。
  • source searchでraw CoreGraphics durationの参照はmacOS platform adapter内だけであり、runtime、 platform、calibrationにconsole/logging macroがないことを確認。
  • Shadow policyは常にactualExecution = NONE、actualPresentation = SILENTを維持する。

Manual validation blockers

  • Input Activityのkeyboard/mouse/trackpad reset、Recent/Idle実時間遷移、lock/unlock、sleep/resume。
  • development buildおよび署名済みpackaged buildでpermission promptが出ないこと。ローカル署名済み debug bundleの起動は確認済みだが、実ユーザー操作中のprompt確認と配布用署名は未記録。
  • Agent Runの実Codex long reasoning/Cancel連打/app close/restart/read-only violation。
  • MVP 2から引き継いだreal microphone permission、real gnosis ASR preview/final、2-hour resource soak、Save review/Discard/app-close/TTS blocking。
