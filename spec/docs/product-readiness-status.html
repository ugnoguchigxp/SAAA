保存・削除・復元

保存対象と保護方式
データ 保存場所・保護 削除・復元上の制約
SQLite アプリデータdirectory。会話、設定、run、話者埋め込み、監査を平文保存 DBバックアップ対象。移行前backupを作成。OS全体の暗号化は利用者環境に依存
話者WAV voice profile directory。macOSではdirectory 0700、file 0600。暗号化なし DBバックアップに含まれず、DBだけでは音声profileを復元できない
APIキー macOS Keychain。SQLite、設定JSON、backup、diagnosticsには含めない Provider削除または認証解除時に削除。macOS以外は保存非対応
監査 SQLite。本文、音声、接続先、認証情報を含めず7日保持 起動時に期限切れを削除。画面200件、diagnostics 1,000件まで
診断JSON 利用者が明示的に出力。秘密、本文、個人pathを除外 共有前に利用者が内容を確認する
忘却journal DB外にopaque IDと時刻だけを保存 古いDB復元後も削除済み記憶を復活させない。journal欠損時は安全側に停止
